## 2. 판별 가능 확인

### 판별 기준

- 단일 화면으로 판별 가능: 화면 한 장만으로 위반 여부 판단. 직전 상태·입력·게임 내부 값 불필요
- 화면 요소 간 관계 오류: 둘 이상 요소 간 관계가 틀림. 단일 요소의 렌더링 결함은 제외
- 과제 범위: 2D 플랫포머에서 발생 가능. 다른 장르 사례는 2D 플랫포머 상황으로 바꿔 해석

### 제외 사유

| 사유 | 예 | 대표 사례 |
|---|---|---|
| 연속 프레임 필요 | 캐릭터 공중 정지(점프·낙하와 구분 불가), 이벤트 연쇄·순서 오류. 연속 프레임 판정으로 확장 가능 | T21-808 |
| 직전 상태 필요 | 닫힌 UI 잔류(인벤토리를 닫았는데 드래그하던 아이콘이 남음) | 원본 Rust 사례 (CSV 미포함) |
| 정답 값 필요 | 표시 값 오류(획득 금액과 표시 금액 불일치) | T21-137 |
| 화면에 드러나지 않음 | 맵 경계 이탈(보이는 경우는 R-PHY-01로 판정), 소리, 성능, 강제 종료 | T21-3 |
| 입력·동작 필요 | 이동 불가, NPC의 발판 통과 불가 등 행동·AI 오류 | T21-246, T21-248 |
| 단일 요소 결함 | 개별 스프라이트의 픽셀 오류 등 렌더링 글리치. 기존 렌더링 글리치 탐지 연구 영역 | T21-21, T21-55 |
