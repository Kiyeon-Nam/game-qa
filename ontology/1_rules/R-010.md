# R-010 · 텍스트 영역 이탈

규칙 목록, 전제, 임계값, 반례 처리 기준은 [README](README.md)

- 규칙: 텍스트는 자신이 속한 UI 패널과 화면 안에 완전히 포함된다
- 대상 개념: TextLabel, UIPanel, ScreenBounds
- 관계: contains
- 전제: 없음
- 위반 조건: 다음 중 하나
  - 소속 UIPanel p에 대해 contains(p, x) < text_contain_min
  - 텍스트 x가 p의 경계선에 닿음
  - 텍스트 x가 화면 경계 밖으로 벗어남
- 파라미터: text_contain_min
- 화면에서 보이는 모습: 텍스트가 상자나 화면 밖으로 넘치거나 잘림
- 근거 사례: T21-342, T21-884. 원본 전체에서 "off-screen·cut off·overflow" 포함 48건 중 UI 범주 25건

| 반례 | 처리 유형 | 처리 | 상태 |
|---|---|---|---|
| 패널 없이 화면에 직접 뜨는 텍스트 | 조건 축소 | 소속 패널이 없으면 화면 포함만 검사 | 처리됨 |
| 화면 밖에서 미끄러져 들어오는 연출 텍스트 | - | 단일 프레임 한계 ([0_cases/](../0_cases/README.md) 제외 사유: 연속 프레임 필요) | 한계 |
| 캐릭터를 따라다니는 데미지 숫자가 화면 가장자리에서 잘림 | 개념 분리 | 데미지 숫자는 Text ∧ World라 TextLabel(Text ∧ ScreenFixed)이 아님 | 처리됨 |
