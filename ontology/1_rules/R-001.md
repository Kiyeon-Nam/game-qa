# R-001 · 대상 없는 지시 UI

규칙 목록, 전제, 임계값, 반례 처리 기준은 [README](README.md)

- 규칙: 월드 지시 UI는 나타내는 대상을 최소 1개 가진다
- 대상 개념: WorldIndicator, WorldEntity
- 관계: near, represents
- 전제: P-01
- 위반 조건: WorldIndicator i에 대해 near(i, e) ≤ search_radius인 WorldEntity e가 없음
  - 제외: i가 화면 경계에 닿음, 탐색 반경 안이 ForegroundDecoration으로 덮임
- 파라미터: search_radius
- 화면에서 보이는 모습: 적이 사라졌는데 체력바·이름표만 허공에 남아 있음
- 근거 사례: T21-658

| 반례 | 처리 유형 | 처리 | 상태 |
|---|---|---|---|
| 화면 상단에 고정된 보스 체력바, HUD의 플레이어 체력 | 개념 분리 | 화면 고정 체력 표시는 HUDElement. 이 규칙은 WorldIndicator에만 적용 | 처리됨 |
| 대상이 화면 밖에 있고 체력바만 화면 가장자리에 걸침 | 조건 축소 | 화면 경계에 닿은 지시 UI는 판정 제외 | 처리됨 |
| 대상이 전경 장식(풀숲 등)에 완전히 가려짐 | 조건 축소 | 탐색 반경 안이 ForegroundDecoration으로 덮이면 판정 제외 | 처리됨 |
| 대상 사망 직후 체력바가 사라지는 연출 프레임 | - | 단일 프레임 한계 ([0_cases/](../0_cases/README.md) 제외 사유: 연속 프레임 필요) | 한계 |
