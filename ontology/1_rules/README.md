## 규칙 목록

| 규칙 ID | 위반 명칭 | 규칙 |
|---|---|---|
| [R-001](R-001.md) | 대상 없는 지시 UI | 월드 지시 UI는 나타내는 대상을 최소 1개 가진다 |
| [R-002](R-002.md) | 지시 UI 위치 이탈 | 월드 지시 UI는 나타내는 대상 가까이에 있다 |
| [R-003](R-003.md) | 지시 UI 대응 오류 | 월드 지시 UI는 대상을 최대 1개 나타내고, 한 대상은 같은 종류의 지시 UI를 최대 1개 가진다 |
| [R-004](R-004.md) | 캐릭터 지형 파묻힘 | 캐릭터는 충돌 지형과 일정 비율 이상 겹치지 않는다 |
| [R-005](R-005.md) | 아이템·투사체 지형 박힘 | 아이템·투사체는 충돌 지형 내부에 포함되지 않는다 |
| [R-006](R-006.md) | 고정 오브젝트 부유 | 바닥 고정 오브젝트는 아래쪽이 지형 또는 발판과 접촉한다 |
| [R-007](R-007.md) | 레이어 순서 오류 | 캐릭터는 충돌 지형에 가려지지 않는다 |
| [R-008](R-008.md) | 장비 스프라이트 분리 | 장비는 그것을 든 캐릭터와 접촉한다 |
| [R-009](R-009.md) | HUD 요소 간 겹침 | HUD 요소끼리는 부분적으로 겹치지 않는다 (완전 포함은 허용) |
| [R-010](R-010.md) | 텍스트 영역 이탈 | 텍스트는 자신이 속한 UI 패널과 화면 안에 완전히 포함된다 |

- 규칙 ID는 추가 순서대로 부여하는 순번

## 전제 목록

대상 개념이 화면에 있으면 자명하게 성립하는 조건, 개념 정의로 표현되는 조건은 적지 않음

| 전제 ID | 내용 |
|---|---|
| P-01 | 지시 UI 하나가 대상 하나에 대응 |
| P-02 | 측면 시점이고 중력 방향이 화면 아래쪽 |
| P-03 | 충돌 지형이 항상 캐릭터보다 뒤에 그려짐 |

## 반례 처리

- 반례는 추론으로 작성. 대상 게임의 정상 화면으로 검증 전

| 처리 유형 | 내용 |
|---|---|
| 개념 분리 | 반례 대상을 별도 개념으로 나눠 규칙 대상에서 제외. 형태 축의 라벨링 대상 정의 포함 |
| 전제 보완 | 전제를 구체화해 해당 게임을 적용 대상에서 제외 |
| 조건 축소 | 규칙의 판정 조건을 좁힘 |
| 게임별 규칙 전환 | 전제로 판단할 수 없어 게임별 규칙으로 전환 |
| 임계값 조정 | 임계값 또는 게임별 파라미터로 해소 |
| 관계 계산 보완 | 관계 계산 방식으로 해소 |

| 상태 | 내용 |
|---|---|
| 처리됨 | 처리 유형으로 해소 |
| 한계 | 해소하지 않고 알려진 한계로 인정 |
| 미정 | 대상 게임에서 확인 후 결정 |
