# 화면 수집 목록

- 저장 위치: 비공개 드라이브 폴더 `screens/<게임>/`. 링크는 노션 팀 페이지
  - 유료 에셋(Corgi Engine) 화면이라 레포에 커밋하지 않음
- 형식: PNG, 1920×1080
- 파일 이름: `<게임>_<장면>_<번호>.png`
- 수집 방법 (Corgi): 데모 씬 플레이 모드, Game 뷰 1920×1080 고정, FPS 표시 끔
  - 번호 00: 스폰 직후
  - 번호 01·02: 플레이어를 레벨 안의 다른 위치로 옮긴 뒤
  - 번호 hb: 체력바가 없는 적에 엔진 체력바(MMHealthBar)를 실행 중 부착. 씬 파일은 수정하지 않음
